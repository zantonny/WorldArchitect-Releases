# WorldArchitect downloads

Public Windows releases for WorldArchitect, a local desktop planet and world editor.

[Download the latest release](https://github.com/zantonny/WorldArchitect-Releases/releases/latest).

Download **WorldArchitect-Windows.zip**, extract the entire folder, and run **WorldArchitect/WorldArchitect.exe**. Keep the `_internal` folder alongside the executable. No Python installation is required. Worlds and settings are saved locally on your computer.

This repository hosts compiled application downloads and release notes. The application source is maintained separately. The in-app updater is planned; current releases are installed manually.
